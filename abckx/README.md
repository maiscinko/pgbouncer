# Customizações ABCKX para PgBouncer

Esta pasta contém todas as customizações e integrações específicas do PgBouncer para o ecossistema ABCKX.

## Estrutura

- `api/`: API REST para gerenciamento do PgBouncer
- `config/`: Arquivos de configuração otimizados para Supabase
- `deploy/`: Scripts de deploy e integração com deploy-standalone
- `docs/`: Documentação específica para o uso no ecossistema ABCKX

## Particularidades da Implementação

- Configurações específicas para Supabase
- Suporte para múltiplos pools por módulo
- Integração com o sistema de monitoramento ABCKX
- Gerenciamento via API para automação por IA
